# pacific-flexure-window-dependence

Code and derived data for the recovery of flexural parameters at twenty
circum-Pacific subduction margins without an analysis window.

Every profile-based inversion of a bending profile is fitted over an interval
chosen by the analyst. This archive contains both halves of the argument that
follows from that fact: a windowed least-squares baseline swept across every
defensible interval, which measures how much of the published disagreement the
choice of interval accounts for, and a physics-informed neural inversion that
imposes the thin-elastic-plate equation at collocation points across the whole
profile and so needs no interval at all.

## What is here, and what is not

**Here:** all analysis code, all figure scripts, the traced trench axes, the
per-profile and per-segment derived tables, the window-sweep grid, and the
complete output of the reported run `r02`.

**Not here, by design:**

- *Source grids.* GEBCO, the EarthByte age compilation, GlobSed and the Scripps
  gravity grid are open access, each has its own DOI and its own attribution
  terms, and each is fetched rather than redistributed. See **Data sources**.
- *Derived grids.* `relief.nc` and `shade.nc` total about 5 GB and are written
  by the figure scripts in their first two commands.
- *Figure outputs.* Regenerated by the scripts in `figures/`.

## Environments

Two, deliberately. Resolving PyTorch into the rendering environment moves
several package versions backwards, and the figures report the versions that
produced them.

```bash
# training (Python 3.11.15, PyTorch 2.13.0)
python -m venv .venv-train && source .venv-train/bin/activate
pip install -r requirements.txt

# analysis and rendering (Python 3.12.13, GMT 6.5.0)
conda env create -f environment.yml
conda activate flexure
```

GMT 6.5.0 must be on `PATH` for every script under `figures/` with a `.sh`
extension.

## Reproducing the results

```bash
# 1. trace the trench axes from the PB2002 seed
bash src/axes/trace_axes.sh

# 2. extract and correct the bending profiles
bash src/profiles/extract_profiles.sh
python3 src/profiles/merge_auxiliary.py

# 3. the windowed baseline, and its sweep across every admissible interval
python3 src/inversion/run_window_sweep.py

# 4. the physics-informed inversion (run r02, seed 0)
python3 src/inversion/train_pinn.py --config config/trenches.conf --seed 0
python3 src/inversion/export_deflection.py --run runs/r02

# 5. per-segment tables and the mappable multisegment files
python3 src/postprocess/build_segment_features.py
python3 src/postprocess/build_te_segments.py \
    --axes data/axes/trench_axes_full.gmt \
    --values runs/r02/segments.csv --value te_km \
    --out data/segments/te_segments.gmt
python3 src/postprocess/build_te_segments.py \
    --axes data/axes/trench_axes_full.gmt \
    --values runs/r02/segments.csv --value loss_phys \
    --out data/segments/residual_segments.gmt
```

## Reproducing the figures

Every figure in the article is regenerated from the archived tables. The three
map sheets share one region and one relief base:

```bash
export RELIEF="/path/to/GEBCO_2023.nc"
export REG=116/290/-60/62

SEGMENTS=data/segments/te_segments.gmt       GRDRES=01m bash figures/fig_temap.sh
SEGMENTS=data/segments/residual_segments.gmt GRDRES=01m bash figures/fig_residualmap.sh
SEGMENTS=data/segments/te_segments.gmt VALUES=data/segments/segment_features.csv \
    GRDRES=01m bash figures/fig_parametermaps.sh

python3 figures/fig_teage.py       --table data/segments/segment_features.csv --outdir figures/out
python3 figures/fig_convergence.py --history runs/r02/history.csv             --outdir figures/out
```

`GRDRES=01m` resamples the 15 arc-second grid. The map scripts boxcar-filter
before decimating (`GRDFILT=1`, the default), because plain decimation keeps one
cell in sixteen and `grdgradient` then differentiates an aliased surface.

## Layout

| Path | Contents |
|---|---|
| `config/` | trench definitions and bounding boxes |
| `src/axes/` | automatic tracing of the trench axis from the PB2002 seed |
| `src/profiles/` | profile geometry, extraction, sediment and thermal corrections |
| `src/inversion/` | the neural inversion, the windowed baseline and its sweep |
| `src/postprocess/` | run outputs to per-segment tables and multisegment files |
| `figures/` | one script per figure, content-named |
| `palettes/` | the two colour palettes used, with attribution |
| `data/` | derived tables: axes, profiles, segments, sweep grid |
| `runs/r02/` | the reported run: config, history, per-segment results, deflections |
